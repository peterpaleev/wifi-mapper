# Security and privacy

This is experimental local instrumentation. USB control is an unauthenticated local TCP endpoint; do not expose it through port forwarding or an untrusted network. Survey exports contain radio identifiers and movement traces. Review/redact them before sharing. Use the instrument where you have permission to measure.

Report vulnerabilities through GitHub private vulnerability reporting if enabled on this repository. Do not put credentials or private captures in a public issue. Only the current development branch is maintained; no production security guarantee is implied.
